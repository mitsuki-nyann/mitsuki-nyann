# キャラクター画像

`maid.png` は、ユーザーが提供した参考画像をもとに作成した透明背景のドット絵です。
黒髪・金縁の眼鏡・白い花飾り・黒いメイド服と白いエプロンを引き継いでいます。
プロフィールSVGには画像データを埋め込みます。画像だけ別の場所にアップロードする必要はありません。

制作指定：DS時代のRPGを思わせる小さな全身キャラクター。四角いピクセルの輪郭、少ない色数、3段階の陰影。眼鏡に手を添えた笑顔。庭・文字・UIは含めず、背景は透明。

生成した画像を加工せずに保存し、画面上の表示サイズをSVGで指定しています。
MITライセンスはプログラム部分に適用します。この画像および参考画像の権利を新しく付与するものではありません。
